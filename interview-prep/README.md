# React + Node.js Interview Prep — Step-by-Step Roadmap

Run Node examples: `node step-XX-*/filename.js`

---

## 10-Step Plan

| Step | Topic | Files | Time |
|------|-------|-------|------|
| **1** | JavaScript Core (closures, `this`, async) | `step-01-javascript/` | 2–3 days |
| **2** | React Fundamentals (components, props, state) | `step-02-react-basics/` | 2 days |
| **3** | React Hooks Deep Dive | `step-03-react-hooks/` | 2 days |
| **4** | React Advanced (performance, patterns) | `step-04-react-advanced/` | 2 days |
| **5** | Node.js Fundamentals (event loop, modules) | `step-05-node-basics/` | 2 days |
| **6** | Express & REST API Design | `step-06-express-api/` | 2 days |
| **7** | Authentication & Security | `step-07-auth-security/` | 1–2 days |
| **8** | Databases & ORM (MongoDB/PostgreSQL) | `step-08-databases/` | 2 days |
| **9** | Full-Stack Mini Project | `step-09-fullstack/` | 3 days |
| **10** | System Design & Behavioral | `step-10-system-design/` | 2 days |

---

## How to Use This Kit

1. **Read** the `INTERVIEW.md` in each step folder — common questions + answers
2. **Run** the `.js` files and observe output
3. **Modify** code and predict output before running (closure/async drills)
4. **Explain aloud** — if you can teach it, you know it
5. **Do** the exercise at the end of each step before moving on
